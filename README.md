# TimeBlock Reader

一个基于 Vite + Vue 3 + TypeScript 的日历应用，用于读取和显示外部应用导出的 SQLite 数据库文件中的时间区块数据。

## 功能特性

- 📅 **自定义日历视图**：不使用现成组件，完全自定义的日历 UI
- 📁 **数据库文件上传**：支持上传 SQLite `.db` 文件
- 🔍 **搜索功能**：搜索事件标题、描述、地点，点击结果跳转到对应月份
- 🔗 **日历分享**：一键生成分享链接，压缩数据放入URL，无需上传db文件即可查看
- ✏️ **字段编辑**：支持编辑事件标题和描述，实时更新
- 🎨 **多种事件类型**：
  - 活动（type: 0）- 色块显示，连续日期自动连接
  - 任务（type: 2）- 圆角矩形 checkbox + 文字，已完成显示打勾
  - 备忘（type: 3）- 色块显示
  - 区间（type: 4）- 横跨多个日期的双向箭头线
  - 习惯（type: 5）- 圆形 checkbox + 文字
- 🎨 **颜色支持**：根据数据库中的 color 字段显示对应颜色（背景、线条、边框）
- ✅ **任务完成状态**：已完成任务显示打勾checkbox，保持原始颜色
- 📝 **事件详情弹窗**：点击事件查看详细信息（标题、内容、地点、时间范围）
- 🏷️ **日期标记**：为日期添加半透明遮罩、标记文字和贴图
- 🔒 **隐私保护**：支持模糊事件文字，便于截图分享；分享链接中隐私事件保持模糊状态
- 📅 **月份导航**：上一月/下一月切换，点击年月跳转到今天
- 🎭 **贴图系统**：三组贴图可选，支持APNG动态贴图自动重播
- ⏰ **时间显示优化**：同一天的事件只显示一次日期
- 📱 **响应式设计**：支持桌面、平板、手机等多种屏幕尺寸
- 🌓 **主题支持**：自动适配浅色/深色主题
- 🌙 **农历日历**：每个日期单元格右上角显示准确的台湾农历日期，特殊日期（初一、初八、十五、二十二）使用图标显示
- 🎨 **自定义字体**：支持切换字体集（粉圆体、全瀨体），字体偏好自动保存
- 🎮 **动态加载提示**：文件上传时显示游戏风格的打字机效果和状态指示器
- 🔗 **分享模式优化**：分享链接中隐藏编辑和分享按钮，禁用日期标记功能，隐私事件不可点击

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **TypeScript** - 类型安全的 JavaScript
- **Vite** - 下一代前端构建工具
- **sql.js** - 在浏览器中运行 SQLite
- **pako** - Gzip压缩库（用于分享功能）
- **lunar-javascript** - 农历日期转换库（用于显示台湾农历）

## 使用方法

1. 启动开发服务器后，在浏览器中打开应用
2. 点击上传按钮，选择要读取的 SQLite `.db` 文件
3. 应用会自动读取 `timeblock` 表中的数据
4. 日历会显示所有事件，不同类型的事件有不同的显示样式
5. **搜索事件**：点击右上角搜索图标，输入关键词搜索事件
6. **分享日历**：点击分享按钮，生成分享链接，复制后分享给他人
7. **打开分享链接**：直接打开分享链接，无需上传db文件即可查看日历
8. **编辑事件**：点击事件打开详情弹窗，点击编辑图标编辑标题或描述
9. **查看详情**：点击事件或日期空白处打开详情弹窗
10. **日期标记**：在日期弹窗中设置遮罩、文字、贴图（仅限非分享模式）
11. **保护隐私**：点击"保护隱私"按钮模糊事件文字；隐私事件在分享链接中保持模糊且不可点击
12. **切换月份**：使用左右箭头或点击年月标题切换月份
13. **查看农历**：每个日期单元格右上角显示农历日期
14. **切换字体**：使用字体管理器切换字体集（字体偏好自动保存）
15. **分享模式**：从分享链接打开时，自动隐藏编辑和分享功能，仅可查看

## 数据库表结构

应用读取 `timeblock` 表中的以下字段：

- `_id`: 记录 ID
- `uid`: 唯一标识符
- `type`: 类型（0: 活动, 2: 任务, 3: 备忘, 4: 区间, 5: 习惯）
- `title`: 事件标题
- `color`: 颜色代码（数字）
- `location`: 地址
- `description`: 描述
- `allday`: 是否全天事件
- `dt_start`: 开始时间戳
- `dt_end`: 结束时间戳
- `dt_done`: 完成时间戳
- `dt_delete`: 删除时间戳

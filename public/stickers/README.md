# 贴图使用说明

## 贴图位置

贴图文件位于：`/public/stickers/ㄇㄚˊ幾兔－表情貼/`

## 可用贴图

共有 40 个贴图文件，编号从 1.png 到 40.png。

## 使用方法

1. 在日历中点击空白日期格子
2. 在弹出的日期标记窗口中，滚动到"选择贴图"部分
3. 点击任意贴图缩略图选择
4. 选中的贴图会显示在预览区域
5. 点击"清除贴图"按钮可以移除已选择的贴图

## 技术说明

贴图路径格式：`/stickers/ㄇㄚˊ幾兔－表情貼/{编号}.png`

例如：
- 第 1 个贴图：`/stickers/ㄇㄚˊ幾兔－表情貼/1.png`
- 第 40 个贴图：`/stickers/ㄇㄚˊ幾兔－表情貼/40.png`

## 注意事项

- 贴图文件需要在 `public` 目录下才能正确访问
- 如果贴图无法显示，请检查文件路径是否正确
- 建议贴图文件大小不超过 500KB，以确保加载速度
